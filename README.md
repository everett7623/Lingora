# Lingora

AI-native multilingual plugin for WordPress. One set of posts, directory URLs like `/de/`, and a live visual editor.

- Author: [everettlabs](https://everettlabs.dev)
- Requires: WordPress 6.4+, PHP 8.1+

Install by copying this folder to `wp-content/plugins/lingora`, then connect an AI provider under **Lingora → AI Connection**.
